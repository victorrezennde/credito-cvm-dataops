# credito-cvm-dataops
Se quiser investir seu dinheiro em fundos crédito privado sem olhar no seu app do banco e corretora, aqui é o lugar kkk

Pipeline de integração de dados financeiros da CVM utilizando Python, SQL, Apache Airflow, GCP (GCS/BigQuery) e técnicas de DataOps.

O objetivo é realizar a integração dos dados públicos da CVM, no padrão 175, para calcular a rentabilidade de fundos de crédito. Com isso, poderemos saber os fundos que tem trazido maior rentabilidade nominal e frente ao CDI em janelas dinâmicas de tempo.
